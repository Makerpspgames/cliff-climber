# متسلق الجرف — Cliff Climber

لعبة تسلق بسيطة تعمل مباشرة في متصفح الهاتف أو الكمبيوتر، دون Backend أو مكتبات خارجية.

## التشغيل محليًا
افتح `index.html` في متصفح حديث. لا تحتاج إلى تثبيت أي شيء.

## التحكم
- اضغط باستمرار على زر اليد اليسرى أو اليمنى للتشبث بأقرب نتوء صخري.
- استخدم اليدين بالتبادل وحافظ على قبضة واحدة على الأقل.
- زر ▲ يساعد على الصعود عند وجود قبضة، وزر ▼ يساعد على النزول.
- على الكمبيوتر: A لليد اليسرى، D لليد اليمنى، الأسهم للحركة.
- زر ⛶ لتفعيل وضع ملء الشاشة (قد يتطلب متصفح الهاتف تفاعلًا مباشرًا مع الزر).

## النشر المجاني على GitHub Pages
1. أنشئ Repository جديدًا على GitHub.
2. ارفع الملفات الثلاثة: `index.html`, `style.css`, `game.js` (ويمكنك رفع README أيضًا).
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch، ثم `main` و`/(root)`، واضغط Save.
5. بعد اكتمال النشر سيظهر رابط اللعبة في صفحة Pages.

اللعبة تستخدم Local Storage لحفظ أفضل ارتفاع على نفس المتصفح والجهاز.
